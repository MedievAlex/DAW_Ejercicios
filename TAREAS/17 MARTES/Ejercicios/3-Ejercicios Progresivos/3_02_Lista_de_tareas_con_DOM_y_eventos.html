Ejercicio 02. Lista de tareas con DOM y eventos

Construye una mini lista de tareas con un input y un botón "Añadir". Cada tarea debe aparecer en una lista y tener botón de "Eliminar".
- Usar querySelector/getElementById para seleccionar elementos.
- Crear nodos con createElement y añadirlos con appendChild.
- Controlar eventos click e input.
