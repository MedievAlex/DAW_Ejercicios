Ejercicio 04

Duplicar el ejercicio de login (el primero), vamos a modificarlo. Lo primero, la página de login para que sea un PHP. En el fichero php de proyecto define 3 variables llamados user y password. En user se guardará un nombre de usuario y en password se guardará un hash de una contraseña. Ver documentación aquí. • Cuando el usuario se loguea el servidor controlará si la contraseña y el password coinciden (ver documentación), si es así aparecerá un mensaje indicando que el login ha sido correcto. • Si el usuario o contraseña son incorrectos se redireccionará a la página de login y abajo del formulario aparecerá un mensaje de “usuario o contraseña incorrectos” en rojo.
