Ejercicio 03. Ficha de alumno dinámica

Crea un formulario con nombre, email, edad, provincia (select) y checkbox de aceptación. Valida cada campo y evita el envío si hay errores.
- Validar nombre con expresión regular (solo letras).
- Validar edad entera entre 16 y 85.
- Mostrar mensajes de error bajo cada campo.
- Deshabilitar el botón Enviar hasta que todo sea válido.
- Controlar submit con preventDefault().
